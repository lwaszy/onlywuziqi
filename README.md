# 五子棋 AI 对战

基于 Android 开发的五子棋人机对战游戏，20x20棋盘，四档AI难度可调。

## ✨ 功能

- 20x20 棋盘
- 四档AI难度：简单 / 中等 / 困难 / 大师
- 支持玩家先手 / AI先手切换
- Material Design 风格

## 🛠️ 技术

- 纯 Java 开发
- Canvas 绘图
- AIDE Pro 开发环境

## 📦 如何运行

使用 Android Studio 或 AIDE Pro 打开项目，点击运行即可。
